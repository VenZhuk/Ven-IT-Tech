# День 5. ООП — Варіант 3: Бібліотека

Повний консольний модуль C++17. Класи винесені в `domain.h/.cpp`, контейнер і фабрика — в `registry.h/.cpp`, меню — в `oop_task.h/.cpp`. `main.cpp` — автономний запуск; для загального навчального комплексу приєднайте модуль до пункту 5 головного меню (не компілюйте два `main.cpp`).

## Компіляція (MSYS2 UCRT64)

Відкрийте термінал у каталозі проєкту:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp domain.cpp registry.cpp menu_utils.cpp oop_task.cpp -o library.exe
./library.exe
```

На Windows бажано встановити UTF-8 для термінала: `chcp 65001` (у CMD) або користуватися MSYS2 UCRT64.

## Робота

1. Запустіть програму; пункт `11` додає 4 демонстраційні видання й 2 читачів.
2. Пункт `7` — додати читача, видати, повернути, подовжити, сплатити штраф, подивитися боржників і топ-3.
3. Пункти `8` і `9` зберігають/завантажують каталог та читачів із поточними позиками у `data/oop_library.txt`.
4. Пункт `10` виконує контрольні приклади з документа та додаткові тести.

## Контрольні значення

- Book, 30 днів: 18 грн
- DVD, 5 днів: 10 грн
- Magazine, 7 днів: 0 грн
- EBook, 40 днів: 0 грн
- Book, 1 подовження (21+10 днів), 30 днів: 0 грн, 1 подовження залишилось

## Архітектура та особливості

- `Library` **володіє** виданнями через `vector<unique_ptr<LibraryItem>>` (композиція).
- `Reader` містить **невласні** `LibraryItem*` (агрегація); видане видання видаляти заборонено.
- `lateFee()` — невіртуальний шаблонний метод, що викликає віртуальні `loanDays()` і `finePerDay()`.
- `Book`, `Magazine` реалізують `IRenewable`; `EBook` успадковує інтерфейс через `Book`, але перевизначає `renew()` як заборонену операцію і має 0 доступних подовжень.
- `clone()` створює копію з новим ID.
- Реєстр фабрик створює потрібний тип за тегом з файлу; пошкоджені записи пропускаються зі звітом.
- Три сортування, лямбда-фільтрація, порівняння `<`/`==`, шаблонна `maxBy` з двома застосуваннями в тестах.
- `diagram.mmd` — UML Mermaid. Для перегляду вставте код на mermaid.live.

**Зауваження:** при завантаженні створюються нові автоматичні ID видань. Зв'язки з читачами зберігаються через індекси каталогу й відновлюються. Файл формату `LIBRARY_V2` призначений для цієї програми.

## Короткий звіт

**Тема:** Бібліотека (видання та читачі). **Мета:** закріпити інкапсуляцію, наслідування, поліморфізм, інтерфейси, фабрику та файлове збереження.

**Висновок:** розроблено консольну систему обліку бібліотеки. Абстрактний `LibraryItem` визначає спільний контракт видань; похідні класи реалізують різні строки видачі та тарифи штрафів. Реалізовано перевірку ліміту 5 примірників, заборону подвійної видачі й видачі за наявності боргу, повернення та сплату штрафів, подовження, статистику, пошук, сортування, збереження й відновлення. Контрольні розрахунки перевіряються через меню самотестування.

## Якщо в консолі замість українських літер «кракозябри»

Використовуйте **Windows Terminal** або термінал VS Code зі шрифтом Consolas / Cascadia Mono.
В `main.cpp` для Windows налаштовано `SetConsoleOutputCP(CP_UTF8)` і `SetConsoleCP(CP_UTF8)`.
У PowerShell/cmd можна додатково виконати `chcp 65001` **перед** запуском.
Зберігайте вихідні файли в кодуванні UTF-8 (у VS Code: нижній рядок стану → UTF-8).
Для MSYS2 UCRT64 збирайте: `g++ -std=c++17 -finput-charset=UTF-8 -fexec-charset=UTF-8 main.cpp domain.cpp registry.cpp menu_utils.cpp oop_task.cpp -o library.exe`.
Якщо використовуєте старий cmd.exe, відкрийте програму у Windows Terminal: старий шрифт консолі може не відображати кирилицю.
