ДЕНЬ 2 — Облік студентів (C++17)
Windows: build_windows.bat -> run_windows.bat
MSYS2 UCRT64 g++ має бути доступний у PATH.
Альтернатива: g++ -std=c++17 main.cpp menu_utils.cpp types_task.cpp -o Day2.exe
Дані зберігаються тільки у пам'яті та зникають після виходу (вимога Дня 2).
Вводьте ПІБ у форматі «Прізвище Ім'я». Для коректного показу кирилиці використовуйте Windows Terminal та UTF-8.
Сортування/пошук кириличних прізвищ: порівняння байтів UTF-8, без мовної локалізації.
