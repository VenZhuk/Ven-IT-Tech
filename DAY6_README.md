# День 6 — локальна інтеграція C++

## Запуск

**Windows / MSYS2 UCRT64:** запустіть `run_day6.bat`.

**macOS / Linux:** `./run_day6.sh` (потрібні g++ із підтримкою C++20 і заголовки Boost.PropertyTree).

Відкрийте **http://127.0.0.1:18080** та перейдіть у розділ «День 6».

Сервер слухає лише 127.0.0.1; файли HTML/JS/CSS віддаються з поточної теки. Вебсторінка відправляє POST `/api/compute` із `day=6`, `variant=1..10`, `data` та додатковими полями. Обчислення виконуються в C++ (`day6_api.h`), не в JavaScript. Окремий `day6.html` не потрібен: День 6 інтегровано в `index.html` через `app.js` і `day6_module.js`.

## Автотести

`g++ -std=c++20 -O2 tests6.cpp -o tests6 && ./tests6`

Для санітайзерів: `g++ -std=c++20 -g -fsanitize=address,undefined -fno-omit-frame-pointer tests6.cpp -o tests6_asan && ./tests6_asan`.

## Обмеження

Це робоча навчальна інтеграція десяти демонстрацій, **не повне виконання всіх критеріїв рівнів А/Б/В** з методички. Зокрема, `LinkedList` використовує `std::list`, частина контейнерів має STL-внутрішню основу; не для кожного контейнера реалізовано власний ітератор, збереження у бінарний файл, Student/Song/Task, серіалізацію, окремі меню, бенчмарки та 10 000 операцій **для кожного** варіанта. Тести охоплюють 10 000 випадкових операцій для чотирьох контейнерів, плюс базові перевірки інших. Для повного академічного звіту ці частини потрібно доповнити.

Вихідний `server.cpp` використовує `std::string::ends_with`/`starts_with`, тому збірка всього сервера вимагає **C++20** (не C++17). Самі шаблонні класи використовують переважно C++17.

GitHub Pages — статичний хостинг; він не запускає C++-сервер. На опублікованому сайті День 6 повідомить про недоступність API, доки не буде окремого хостингу бекенду.
